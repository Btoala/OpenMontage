What this inventory establishes.

Search and verification limits

    A successful upload, an audio stream or an intact archive does not establish a complete, usable production backup. Open each record for the specific checks performed and checks still reported or missing.

    Verification vocabulary

    Safe export

    JSON and CSV contain only the current filter results, the approved project scopes and fixed inventory fields. Executable, signed and credential-bearing links are excluded, and CSV formula-leading values are escaped. The snapshot contains private production metadata: keep it private.

    Free-text fields still require review during each refresh. Export controls do not guarantee detection of every possible sensitive statement. Original source permissions still govern retrieval links.

    Preservation boundary

    This page reads a fixed snapshot. It has no production controls, upload, migration endpoint, provider connection or background refresh. Production originals stay in their existing locations. Future copies or restores must be planned separately and require explicit approval.

    Repository source and generated production files have different backup needs. A Git repository that excludes workspaces, media or music does not preserve those bytes.
